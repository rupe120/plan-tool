Retaining split assessment for this population is new cost, not continuity, which cuts against the Problem statement's stated goal of not "spending calls that were never necessary."
  - Fix: Rewrite the Overview's outcome-vocabulary sentence so it states plainly whether a direct-ready source is always subject to the pre-write split assessment (matching Architecture/Acceptance criteria) or exempt from it, and if subject to it, describe that as a deliberate new check for this population rather than "the existing" assessment, since today's canonical-small shortcut skips split determination entirely.
