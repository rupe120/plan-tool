# Presentations

Keep audience-facing slide decks and presentation assets here. Each presentation
should explain its subject without relying on a development session's context.
Link to the maintained guide, explanation or evidence record for details.

Demo walkthroughs and presenter runbooks belong in [demos](../demos/README.md).
Per-session demo updates, recording progress and publication tasks belong in
[handoffs](../../handoffs/README.md). Measurements belong in
[evidence](../evidence/README.md), rather than only in a slide.
