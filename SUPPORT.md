# Getting help

- **A question about using plan-tool:** read the [README](README.md) and the
  [use cases guide](docs/how-to/use-cases.md), then
  [ask a question](https://github.com/rupe120/plan-tool/issues/new?template=question.yml).
- **Something broke:** use the [RUNBOOK](RUNBOOK.md) for failed or surprising
  results, then
  [report a bug](https://github.com/rupe120/plan-tool/issues/new?template=bug_report.yml).
- **An idea:** [request a feature](https://github.com/rupe120/plan-tool/issues/new?template=feature_request.yml)
  and describe the problem before the solution.
- **A security problem:** do not open an issue. Follow [SECURITY.md](SECURITY.md).
- **A conduct problem:** follow the [code of conduct](CODE_OF_CONDUCT.md).

plan-tool is maintained on a best-effort basis, so there is no guaranteed
response time.
