- HIGH `[transcript-capture-trigger]`: The Architecture section states two things about the same event that read as opposite outcomes for one case: "Raw NDJSON transcript capture fires automatically when a call fails or stalls" against "A call that completes normally never gets one, which is what keeps it from becoming a default durable artifact." The plan elsewhere uses "stall" precisely for the non-terminal 300-second `ClaudeCallStallSuspected` marker (Testing: "exactly one stall marker per call"), distinct from the terminal `silence_timeout` reap at 900 seconds. The Risks section says exactly this shape — "a long single tool-use burst with no incremental stream event" — is a real pattern across the seven callers, so the resolution isn't academic: it decides whether transcripts stay rare, as "never a default durable artifact" intends, or become routine for any caller with occasional slow tool bursts.
  - Fix: define step 10's trigger as the terminal outcome only (rc != 0, `configured_timeout`, `silence_timeout`, or `spawn_failure` — never a completed call whose stall marker later cleared), and reword the Architecture bullet so the two sentences no longer contradict each other.
