Step 3 says a removed-row reference "neither joins nor is required of" the owning set. The motivating Integration Decisions block names the removed `decision-exclude-repo-browsing`. If that block names only one other live row, its owning set has one member, and it falls into this undecided case.   - Fix: Have step 1 state whether a one-member owning set is correctable. Then align step 3's issuance rule and step 4's target check, and add a test for the one-live-row-plus-removed-reference block.
