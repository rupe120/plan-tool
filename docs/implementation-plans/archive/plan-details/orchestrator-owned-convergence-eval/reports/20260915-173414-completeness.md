  ```
  Architecture: “A `false-premise` record pairs an anchor-resolved canonical-plan premise with an anchor-resolved captured-input fact that contradicts it.”
  ```

  A reader can either re-read live code to validate a record or reject code-backed premises as uncaptured, producing different no-window `redesign-or-rescope` behavior from the same saved report.
  - Fix: Define the closed set of captured fact types, including permitted code facts, and bind each fact’s anchor and identity to the audit revision for producer parsing, adapter admission, and tests.

  - Fix: Define an exact expected evaluator event sequence and validate every appended event and terminal position at M1–M4, refusing valid-but-extra, duplicate, reordered, or premature terminal events.

  - Fix: Define a closed structural-finding scope and explicit identity/severity rules that partition recurrence, narrowing, and insufficient-history cases before the judge receives eligible outcomes.
