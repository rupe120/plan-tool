- HIGH `[canonical-unselected-content]`: Architecture’s “canonical parsed artifact” and byte-preservation guarantee, step 3 (`Atomically apply authorized row, prose, and ordering operations; preserve the local profile and unselected content`), Testing, and the untouched `awaiting-review` criterion never define the stage route’s input-canonicality boundary. At HEAD, `roadmap.py:_load_predecessors` accepts any parseable predecessor and `_write_artifact` re-renders the entire parsed artifact; `roadmap_artifacts` ignores unknown frontmatter, while the selector-bound local route explicitly requires `render(parse(text)) == text` in `roadmap_revision:preflight_feedback_revision`. A parseable hand edit can therefore normalize or drop unselected frontmatter without any authorized operation.
  - Fix: Define whether stage envelopes require a render-canonical predecessor or preserve parseable noncanonical text, then make that choice enforce the no-drift guarantee and test it.
- HIGH `[decision-anchor-retargeting]`: Architecture’s `edit-row` says only “On `PlansArtifact`, it cannot retarget an existing `AssumptionRow.consuming_plan_ids` or `DecisionRow.anchor`,” while `Out of scope` bans “Retargeting an existing plan ordering, assumption consumer, or decision anchor.” Risks, Testing, and acceptance criteria limit the check to plan-internal relations; `roadmap_gates:check_decision_records` accepts a valid changed anchor and `check_settled_decisions` protects only settled decisions, so an edit can retarget an existing pending decision in domain, constraints, or components.
  - Fix: Make the decision-anchor boundary apply consistently to every stage-envelope edit and cover that authority rule in the matrix, context, merge, tests, and acceptance criteria.
