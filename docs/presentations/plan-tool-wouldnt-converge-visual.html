When the Plan
Wouldn't Converge

a true story from one authoring session

Eight audits. “Converged” every time.

The loop reported no-blocking-findings — and surfaced fresh correctness bugs anyway.

Every fix spawned the next finding

Whack-a-mole is the signature of fighting a plan's shape, not its prose.

A structural edit jammed into a prose loop

The loop assumes apply never changes step identity. A split renumbers it mid-iteration.

apply can only add prose

It fixes under-specification — never over-complexity. So the plan grew, and the audit kept biting.

Seed → regenerate, not plan surgery

One over-packed step became a clean 9-step spine — each step one concern, one change-type.

The blind spot became the next feature

Diagnosing the failure produced a seed for the capability that would catch it next time.

What plan-tool bought us

A plan you can implement without fighting it — because the tool made us fix its shape, not just its words.
