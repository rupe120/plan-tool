- [APPLIED] Step 4 (`branch_ownership.py`) never implements the "a plan ad-hoc-bound elsewhere forfeits the convention claim on its derived name" rule that the Architecture, step 7's disambiguation safety argument, and two acceptance criteria depend on. `convention_owner(branch, registered_slugs, prefixes)` is specified pure and returns any registered slug whose `convention_names` contains `branch`, with no `get_binding` check; `branch_owner` adds only `reverse_binding(B)` ahead of it. Consequently after a `create` collision disambiguation binds P to `plan/<slug>-2`, `branch_owner(plan/<slug>)` still returns P (OWNER_CONVENTION), so a developer on the foreign `plan/<slug>` who runs P is classified Tier-2 P-owned and **silently proceeds** — directly violating the AC "`branch_owner(plan/<slug>)` does not return P … treated as Tier-3 (orphan-pattern)". The same omission makes an `attach-branch P JIRA-1` override leave `plan/P` reading as Tier-2 P-owned. The plan's prose also half-hides this: the two-lookup example says "`plan/P` stays P's reserved convention name" (reads as still-owned-by-P) while the `convention_owner` definition says P "forfeits the convention claim" (reads as not-owned-by-P), and the spec follows the former.
- [APPLIED] Step 7's summary claims the create-collision gate is "a byte-for-byte no-op" in "any non-git / detached-HEAD tree" because "`branch_exists` returns its `False` sentinel" — but `branch_exists` (step 2) runs `git show-ref --verify refs/heads/<name>`, which returns `True` for an existing local branch *regardless of HEAD state*. On detached HEAD with an existing `plan/<slug>`, the gate therefore runs, and `current_branch` returns `None`, so `invocation` is `None` and the restore-on-failure path (`checkout_existing_branch(repo_root, invocation)`) has no branch to return to — unlike step 5's guard, which explicitly no-ops when `current_branch` is `None`. — - `docs/implementation-plans/plan-details/attach-branch-to-plan/07-create-time-namespace-collision-warning.md`: rewrote the summary's detached-HEAD claim to cite an explicit `current_branch is None` no-op instead of a false `branch_exists` `False` sentinel
- [APPLIED] The Architecture's injectivity argument ("Because the slug is unique the slug→branch map is injective") is unverified: a slug is the filename stem (`locator.py:slug_from_filename`), and the manifest is a list of paths across arbitrary directories, so two registered plans in different dirs can share a slug and derive to the same `<prefix><slug>`. No step enforces registered-slug uniqueness or defines `convention_owner`'s behavior when multiple registered plans match B, leaving Tier-2 ownership ambiguous.
