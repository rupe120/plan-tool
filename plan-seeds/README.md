# Existing plan seeds

New seeds default to [docs/implementation-plans/plan-seeds](../docs/implementation-plans/plan-seeds/).
This directory retains existing seeds and their current references. No seed files
are moved or migrated automatically. Continue using their exact paths with
`plan-tool create <slug> --from-existing plan-seeds/<file>.md`.

Use the new directory for new briefs. Explicit output destinations remain
supported; existing roadmap publications retain their original destination.
