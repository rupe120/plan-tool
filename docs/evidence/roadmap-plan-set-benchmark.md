## Instrument observations

Unique granularity decisions in the replay telemetry: worker 9 assessments, each split=4; infrastructure 4 assessments (create split=0, later split=1); SPA 3 assessments, split=0; pipelines 3 assessments, split=0 before the final audit. The worker signals exist and require interpretation; do not call them absent. Infrastructure’s reported directory split answers a different question. SPA/pipeline no-split results do not assess complete-set delivery ownership. This is not evidence of a universal size threshold.

Current source supports component-to-several-plan `split` dispositions in `ROADMAP_FORMAT.md`. Stage-four mapping can already express several plans per component. Existing materialization nevertheless reads one accepted row at a time, and ordinary create assesses one seed, not the selected artifact bundle as a set. The improvement belongs in the existing stage-four mapping and per-row seed handoff. Materialization retains accepted rows; a changed accepted mapping uses existing revision and approval routes.
