# `plan-tool init`

## Usage

```
plan-tool init [-h] --intent INTENT [--non-goal NON_GOAL] [--decision DECISION]
```

## Options

| Option | Default | Description |
| --- | --- | --- |
| `--intent` `INTENT` | — | confirmed project-level intent; supplied by the operator, never inferred |
| `--non-goal` `NON_GOAL` | — | confirmed project-level non-goal; may be repeated |
| `--decision` `DECISION` | — | confirmed project-level decision; may be repeated and is not categorized |
