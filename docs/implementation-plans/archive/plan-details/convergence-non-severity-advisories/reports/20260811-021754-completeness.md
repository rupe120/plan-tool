  - Fix: restrict edit-drift materiality to the conceptual sources (`plan-correctness` / `plan-completeness`, the same `CONCEPTUAL_SOURCES` set impact-recurrence's impact field already scopes to by construction), and add a test fixture proving a recurring deterministic finding (e.g. a path-style violation) never counts toward edit-drift.

  - Fix: define what identifies a matched seam group for the tie-break — e.g. the group's first-seen anchor slug, or a synthesized key from the earliest finding's step focus/anchor — since raw finding ids are explicitly not stable.
