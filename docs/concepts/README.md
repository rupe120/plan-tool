# Concepts and project briefs

Keep problem statements and project-sized ideas here: the intended users,
desired outcomes, constraints and non-goals that help a reader frame work before
choosing an implementation. These briefs can feed roadmap or plan authoring.

Use [implementation plans](../implementation-plans/README.md) for ordered work,
[design proposals](../design-plans/README.md) for a proposed mechanism, and
[handoffs](../../handoffs/README.md) for session pickup status. A concept does not
establish a shipped contract or authorize execution.
