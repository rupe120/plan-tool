So this “TTRPG World Builder” project. The idea is that all notes at the end of the day are markdown. This allows for a user to import/export to/from something like Obsidian or the like into the application (web). A user can create notes in the application WYSIWYG editor.

CORE FEATURE: NOTES

A user (dungeon master) logs in and creates a “world”/setting (a collection of notes about their world); a user can then invite other users (players) to their world.

Notes are about People, Places, Things, Events. Notes that are draft are only visible to the owner, a note that is published would be visible to the players. A published/shared note may still have information that is marked “secret”. A note’s secrets can be shared with individuals or groups of individuals.

Notes would support “wiki links” ([[some note | display text]]) to allow a user to click on that link and go to the linked note, hovering the link generates a popup/preview of its contents.

Notes would have a suggested template for “People” ,”Place”, “Thing” “Event”.

CORE FEATURE: SECRETS

A section of a note that has information there that is yet unknown to the players. Example: Players can see the note about Iarno Albrek, a local low level wizard that is a bit clumsy and not well schooled in the arcane arts, what they don’t know is that he is actually “Glassstaff” leader of the group of bandits known as the Red Brands; his clumsiness and lack of skill are simply a cover and he is much more deadly than the players yet know.

CORE FEATURE: GRAPH

Linked notes show up with a graph (like obsidian does); however the graph never shows the user links to unpublished notes,OR to information they do not have visibility to.

CORE FEATURE: MARGINAILIA

If this were physical pen and paper marginalia is when a user (typically) player would write in the margins of said paper notes to themselves about the content. For example a player has visibility into a note about a person "Captain Flanigan”. The player can highlight a sentence or paragraph and add a note for example “I think Flanigan is actually a Dragon Cultist”. Marginalia is only visible (by default) to the owner, but can be shared to the DM or other players either individually or by group.

FEATURE: GROUPING

Notes of like type can be grouped together. For example, a note could be about a shop (place), that is in a town (place), that is in a county (place), that is in a kingdom (place) that is in a region; again (place).

A note about an event has a time associated with it, “when did it happen?” events can be grouped by chronology; years, eras, eons.

Groups of “People” notes might suggest an organization; Freemasons, Illuminati are real world examples, or perhaps the Harpers, or a thieves guild for fantasy examples.

FEATURE: MAP

A larger world or area map can be uploaded by the world owner and then customizable map markers added, which then can link to notes about the place for that map marker. For example a map of Planegea has a map marker for the ‘Tree of Koh’, hovering the map marker shows a preview of the note for the ‘Tree of Koh’, clicking on it opens the note.

A map would have a scale added to it for estimates of distance. The ability to mark regions, the ability to make paths, example; the ‘Tree of Koh’ is in the Region called the ‘Great Valley’ the Great Valley would have a linked note as well. Paths for example would be “The Chief’s Highroad” with again linked notes.

FEATURE: CALENDAR

A world should have a calendar; that calendar might be the Gregorian Calendar, or a fantasy calendar like Harptos for the Forgotten Realms of D&D or maybe Ebberon, or Greyhawk, or a fully custom calendar with the concept of days, weeks, months, years and moon phases.

A worlds calendar would have time groupings example -∞ to 0 (pre history, we know things happened, but the exact times are unknown (the gods of the realm created this world), 0 - XX, could denote an era example (the dawn wars; a group of events about this point in history), XX - ∞; the current era in which the world exists; this is the time frame in which the players of this world exist.

FEATURE: TIMELINE

A Timeline view allows players to see a chronological grouping of events categorized by various epochs. Some events have an order in which they occurred but not a specific day/time. Other notes would know the exact time an event occurred. A timeline would have different views, a traditional timeline, a ganttview, and of course a calendar would be super helpful. The ability to group events by “ages” “era” “epochs” and the ability to filter out groups of events like “the Dawn War” or “Age of Creation”.

FAR FEATURE: AI Note Taker

An AI agent that is able to join a call like Google Meet or Discord and listen to players playing a session; understand the players and understand who each player is playing (their character) and take session notes about the things that occurred that play session. Is then able to create a group of notes in the application that is its own type “session note”. Session notes can still wiki link back to world notes about people, places, things, or events that occur or are referenced that session.

FAR FEATURE: AI Lookup

The ability to have AI to use the notes of the world for RAG and become a subject matter expert on both the world and the sessions played there in.  This would allow the player to open a chat either in the application or perhaps in external applications of the AI is linked like discord and ask “who was that shop keeper we came across a few sessions back that was selling that really cool magical spear?” or “can you summarize the “dawn wars for me”; of course only divulging information that the player(s) would have access too.
