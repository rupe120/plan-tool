Reusing that set for bad-fix would let identity-only or disappearance-only history satisfy the advisory while acceptance requires same-issue identity **and** an intervening remedy note.
  - Fix: state in Architecture, step 3, and Testing that bad-fix scans collapsed completeness passes on its own predicate (identity match plus a non-empty intervening note on the matched prior finding) and does not inherit edit-drift's disappearance or resolved-without-note prior-apply membership.
